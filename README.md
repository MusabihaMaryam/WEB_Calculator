A simple, responsive calculator built using HTML, CSS, and JavaScript. This project performs basic arithmetic operations through an interactive and user-friendly web interface.

Features
Addition, subtraction, multiplication, and division
Clean and responsive UI
Button-based input system
Real-time display updates
Basic input validation
Lightweight and fast performance
Technologies Used
HTML
CSS
JavaScript
Project Objectives

The objective of this project is to develop a simple web-based calculator that strengthens core front-end development skills, including DOM manipulation, event handling, and responsive UI design.

How to Run
Download or clone the repository
Open the project folder
Run the application by opening:
index.html

Or simply double-click index.html to launch it in your browser
